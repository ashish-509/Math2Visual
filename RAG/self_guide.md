## Quick Start

### Option 1: Automated Setup 
```bash
cd RAG
setup.bat      # Windows
# or
python setup.py  # Any OS
```

### Option 2: Manual Setup 
```bash
cd RAG
pip install -r requirements.txt
python test_rag.py # Test components
python setup.py    # Full setup
```


### Option 3: Run Enhanced App
```bash
cd RAG
streamlit run app_with_rag.py
```
